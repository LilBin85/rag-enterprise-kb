# 项目演进摘要

## 定位与演进

项目从“企业知识库 RAG 问答”演进为面向制度与技术规范的 Durable AI Agent 后端：在租户与 ACL 隔离下完成文档摄取、证据检索、只读研究，以及带人工审批的受控写入。核心目标不是堆叠 Agent 概念，而是让任务可恢复、证据可追溯、写入可审计。

## 架构收敛成果

1. **API 与执行解耦**：API 只认证、授权、持久化任务或恢复命令；不构造 Agent、不执行工具。
2. **后台职责拆分**：任务执行、文档摄取和投影收敛为独立 Worker 进程模式，以 PostgreSQL 队列协调。
3. **依赖方向明确**：应用层依赖端口，基础设施实现端口；边界测试约束反向依赖。
4. **检索核心统一**：同步 Fast Path 与可恢复 Durable Path 复用同一 Retrieval Core，避免授权与证据语义漂移。

## 当前技术边界

- PostgreSQL 是任务、授权、审计和恢复语义的事实源；Qdrant 是带世代校验的检索投影。
- Agent 使用固定工具集；所有写入均经过 HITL 与审计，不提供无约束自治执行。
- 项目聚焦后端与可复现实验，不包含面向终端用户的完整前端产品，也不将本地演示语料或密钥作为公开运行前提。
